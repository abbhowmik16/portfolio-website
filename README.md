# Amiya Bhowmik — Portfolio

A responsive, dependency-free professional portfolio inspired by the supplied Tanya Srivastava portfolio. Content comes from Amiya's supplied resume.

Serve `dist/` with any static web server, for example:

```powershell
python -m http.server 3000 --directory dist
```

Open http://localhost:3000. Edit `dist/index.html`, `dist/styles.css`, and `dist/script.js` to update the site. The downloadable resume is in `dist/assets/`.

Features include responsive navigation, expandable professional highlights, section navigation, downloadable PDF, and direct email, phone, and LinkedIn links. No form service or build step is required.
